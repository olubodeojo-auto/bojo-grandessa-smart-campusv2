# GitHub Copilot Development Guide

Before writing code:

1. Read ARCHITECTURE.md.
2. Preserve completed modules.
3. Reuse existing services.
4. Reuse existing components.
5. Maintain coding consistency.
6. Produce production-quality code.
7. Ensure the project builds successfully.

Never redesign completed features without a clear reason.

- User experience
- Stability
- Visual quality
- Performance
